# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Report suspected vulnerabilities privately through the repository owner's available GitHub contact channels. Include the affected page or component, reproduction steps, impact, and any relevant evidence.

## Scope

Security reports should focus on vulnerabilities in the KAI source or its deployment configuration. Do not include passwords, API keys, payment information, or other sensitive personal data in reports.

## Response

Reports will be reviewed and prioritized according to impact and reproducibility. Please allow reasonable time for investigation and remediation before public disclosure.
